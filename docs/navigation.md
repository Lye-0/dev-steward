# ナビゲーション

主要画面は、対象の把握から更新までの流れに合わせます。

| 画面         | 目的                                                   |
| ------------ | ------------------------------------------------------ |
| 概要         | 登録された環境・プロジェクトと実行待ちを把握する       |
| 環境・ツール | 選択した環境のツールを管理元ごとに調査する             |
| プロジェクト | ローカルとGitHubの調査結果を同じ一覧から確認する       |
| 更新         | 更新候補、静的な更新方針、実行計画と進行状況を確認する |

履歴と設定は下部に配置します。狭い画面ではアイコンになっても操作名を保持します。

環境の選択は「環境・ツール」では操作対象、「プロジェクト」では比較・登録対象、「設定」では設定対象です。概要・更新・履歴は全体を表示します。環境を切り替えてもプロジェクトや計画の一覧を絞り込みません。

同じリポジトリの複数の作業場所や参照を保持し、詳細と実行計画には実際の対象環境を表示します。既存の保存データの削除や移行は不要です。

「更新」は横並びの「更新候補／計画・進行状況」タブで表示を切り替えます。矢印・Home・Endキーでも選択とフォーカスを移動できます。OS・アプリ管理元および管理ツール本体の更新操作は「更新候補」に置き、対象環境をその区画で選択します。プロジェクト・計画の統合一覧の絞り込みとは独立しています。

環境・ツールの一覧では更新候補の照合・計画作成を直接実行せず、各項目の入口から「更新」へ環境とツールIDを引き継ぎます。WinGetはパッケージIDも渡します。「更新」の環境操作区画で開発ツールの候補照合、対象版の選択、導入計画、旧版の削除可否確認を行います。対象環境を切り替えた場合、選択中のツールとパッケージIDを解除します。
